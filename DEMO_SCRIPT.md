# 90-second Syllabus SOS demo

Use an owner-approved, non-sensitive assignment PDF with an explicit due date. Keep a screenshot or scan available to show manual-review treatment. Explain that uploaded files are sent to Meta for model analysis. Do not present example workspace data as live extraction.

| Time | On screen | Narration |
| --- | --- | --- |
| 0–10s | Landing page | “Students already have the assignments; the hard part is turning scattered course documents into a realistic next step.” |
| 10–20s | Click **Upload a document**, select the prepared PDF | “Syllabus SOS sends the document to Meta Muse Spark and asks for structured assignments, dates, requirements, and small tasks.” |
| 20–35s | Processing then review queue | “Nothing is added automatically. I can edit or reject each extraction before it changes my plan.” |
| 35–47s | Open the evidence section; show matched quote and page | “For selectable PDF text, the backend checks that the exact date quote appears on a specific page. A quote match is evidence, not a guarantee, so I still review it.” |
| 47–57s | Show a screenshot-derived result or explain the manual-check label; approve the PDF assignment | “Dates read from an image are marked for manual confirmation. I approve only after checking the source.” |
| 57–70s | Weekly workload and preferences; change capacity or preferred day | “The workload view spreads estimated subtasks across my available days and flags days that exceed my chosen capacity.” |
| 70–84s | Open Focus Mode, start/pause timer, complete a step | “Focus Mode turns the recommendation into one timed task, then moves to the next step when I mark it complete.” |
| 84–90s | Approved plan | “Syllabus SOS turns academic chaos into your next actionable step.” |

## Recording checklist

- Start backend and frontend; verify `/api/health` and a successful Muse Spark request first.
- Use a clean browser profile or click **Clear saved plan**. Confirm the source is appropriate to send to Meta.
- Do not include the API key in the recording, terminal, browser URL, or environment settings.
- Make sure the upload opens the review queue, show a quote and page, then approve and confirm the sample plan is replaced.
- Check the calendar/week and preference panel fit the chosen viewport.
- Stop recording if the API fails; do not narrate mock data as live AI output.
